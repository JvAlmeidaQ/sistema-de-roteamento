# Governança e Metodologia de Trabalho

## 📌 Metodologia

O projeto utiliza um fluxo iterativo com entregas orientadas aos marcos oficiais da disciplina de Banco de Dados (DCC060).

## 📋 Definition of Done (DoD)

Um artefato é considerado concluído somente quando:

1. Os scripts SQL executam do zero sem erro no contêiner oficial do PostgreSQL 16.
2. O código ou documentação foi revisado e aprovado via Pull Request por pelo menos um membro do grupo.
3. A nomenclatura e a localização dos arquivos estão estritamente compatíveis com o padrão exigido na Seção 2 do edital de BD.

## 🗓️  Marcos de Entrega (DCC060)

- **E0 (10/09):** Equipe e tema aprovado.
- **E1 (24/09):** Requisitos e regras de negócio (Seções 1 e 2).
- **E2 (16/10):** DER, modelo lógico e normalização (Seção 3).

- **E6 (11/12):** Gatilhos, índices e relatório consolidado (Seções 7.2, 7.3, 8 e 9).
